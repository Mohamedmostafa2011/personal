# التأسيس في البلاغة — سبورة فيديو متزامنة

عرض تعليمي عربي متزامن مع الفيديو:

- الفيديو: `https://youtu.be/xpndcdEmJVs`
- المحتوى: المحاضرة التأسيسية الثانية في البلاغة
- المدة التقريبية: `2:49:27`
- الواجهة: عربية من اليمين إلى اليسار

## المميزات

- 43 مشهدًا تعليميًا منظمًا حسب توقيت المحاضرة.
- نص كبير وعالي الوضوح داخل السبورة.
- تشغيل الفيديو في تبويب خارجي مرتبط.
- مزامنة ثنائية الاتجاه للتشغيل والإيقاف والانتقال والسرعة.
- فصول قابلة للنقر وشريط زمني متزامن.
- ملء شاشة نظيف للسبورة فقط، دون فيديو أو قوائم أو أزرار.
- اضغط `F` لملء السبورة، أو `Esc` للخروج.
- تصميم متجاوب مع الكمبيوتر والهاتف.
- لا يحتاج إلى npm أو أي عملية بناء.

## النشر على GitHub Pages

ارفع هذه الملفات معًا إلى جذر المستودع:

```text
index.html
video_player.html
.nojekyll
README.md
```

ثم:

1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root)`.
4. اضغط **Save** وانتظر رابط النشر.
5. افتح رابط GitHub Pages واسمح بالنوافذ المنبثقة للموقع.

يمكن بدلًا من ذلك وضع الملفات في مجلد `docs` واختيار `/docs` من إعدادات Pages.

## الاستخدام

1. افتح رابط الموقع المنشور.
2. اضغط **افتح الفيديو المرتبط** إذا منع المتصفح الفتح التلقائي.
3. شغّل الفيديو أو غيّر وقته من تبويب الفيديو، وستتغير السبورة تلقائيًا.
4. يمكنك أيضًا اختيار فصل أو وقت من السبورة لتحديث الفيديو.
5. اضغط **ملء السبورة** لعرض المحتوى فقط دون أي عناصر تحكم.

> يجب تشغيل المشروع من GitHub Pages أو أي خادم HTTP/HTTPS. تشغيل الملفات مباشرةً بصيغة `file://` قد يؤدي إلى YouTube Error 153.
