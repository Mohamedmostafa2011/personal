# الأدب في العصر الجاهلي — لوحة تعليمية متزامنة مع الفيديو

موقع ثابت (Static) يحوّل درس **«الأدب في العصر الجاهلي — الشعر الجاهلي»** لمستر عمر ياقوت
إلى **لوحة شرح بصرية تتحرّك مع الفيديو لحظةً بلحظة**.

- الفيديو الأصلي: <https://youtu.be/5QrGXNHTyEA>
- المرحلة: أولى ثانوي — الترم الأول
- المحتوى: **38 لوحة** موزّعة على **15 فصلًا**، مبنية على التفريغ النصّي الكامل للفيديو.

لا يحتاج المشروع إلى Node.js ولا npm ولا قاعدة بيانات ولا خادم خلفي ولا أمر بناء.
ارفع الملفات كما هي على GitHub Pages وسيعمل مباشرة.

---

## 1) محتويات المجلد

```text
adab-jahili-board/
├── index.html          # اللوحة التعليمية + الفصول + شريط الزمن + أدوات التحكم + ملء الشاشة
├── video_player.html   # تبويب الفيديو المستقل + ربط واجهة يوتيوب (IFrame API)
├── .nojekyll           # ملف فارغ مطلوب لـ GitHub Pages
└── README.md           # هذا الملف
```

> يجب أن يبقى `index.html` و`video_player.html` **في المجلد نفسه**؛ فالروابط بينهما نسبية
> حتى يعمل المشروع من مسار فرعي داخل المستودع.

---

## 2) خطوات النشر على GitHub Pages

1. ارفع جميع الملفات المولّدة معًا إلى المستودع (إمّا في الجذر، وإمّا داخل مجلد `docs`).
2. افتح **Settings → Pages** في المستودع.
3. اختر **Deploy from a branch**.
4. اختر الفرع `main` ثم `/(root)` أو `/docs` حسب مكان الملفات.
5. اضغط **Save** وانتظر انتهاء النشر.
6. افتح رابط الصفحات (Pages URL).
7. **اسمح بالنوافذ المنبثقة (Popups)** لهذا الموقع، ليُفتح تبويب الفيديو المتزامن.

يعمل المشروع أيضًا من مسار فرعي مثل:

```text
https://USERNAME.github.io/REPOSITORY/
```

لأن جميع الروابط نسبية، ولا يوجد أي دومين أو اسم مستودع مكتوب بشكل ثابت داخل الكود.

---

## 3) طريقة الاستخدام

1. افتح `index.html` من رابط الموقع المنشور.
2. اضغط **«افتح الفيديو المرتبط»** — سيُفتح `video_player.html` في تبويب مستقل باسم ثابت `linkedVideoTab`.
3. شغّل الفيديو… وستتحرّك اللوحة معه تلقائيًا.

### التزامن يعمل في الاتجاهين

| ما تفعله | النتيجة |
|---|---|
| تشغيل الفيديو | اللوحة تتقدّم معه باستمرار |
| إيقاف الفيديو | اللوحة تتجمّد عند اللحظة نفسها |
| تحريك مؤشر الفيديو (من أدوات يوتيوب) | اللوحة تقفز إلى المشهد المقابل |
| الضغط على فصل أو لوحة في القائمة الجانبية | الفيديو ينتقل إلى تلك اللحظة |
| السحب على شريط الزمن في اللوحة | الفيديو ينتقل معه |
| أزرار تشغيل/إيقاف و ±10 ثوانٍ في اللوحة | تتحكّم في الفيديو |
| تغيير السرعة من اللوحة | تتغيّر سرعة الفيديو |
| إغلاق تبويب الفيديو | تتغيّر حالة الاتصال في اللوحة |
| إعادة فتح المشغّل | يعاد الاتصال بلا حاجة لتحديث اللوحة |

### اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `Space` أو `K` | تشغيل / إيقاف |
| `→` / `←` | ‎+10 / ‎−10 ثوانٍ |
| `↑` / `↓` | اللوحة السابقة / التالية |
| `F` | ملء الشاشة للّوحة فقط |
| `Esc` | الخروج من ملء الشاشة |
| `O` | فتح/تركيز تبويب الفيديو |

### وضع «اللوحة فقط» (ملء الشاشة النظيف)

زر **«لوحة ملء الشاشة»** يطلب ملء الشاشة على عنصر اللوحة نفسه (`#board-shell`)، ويُخفي:
الترويسة، ولوحة حالة الاتصال، وقائمة الفصول، وشريط الزمن، وأزرار التحكم، وكل عناصر الواجهة
غير التعليمية — فلا يبقى أمامك سوى الشرح. ويستمرّ تغيّر اللوحات مع الفيديو أثناء ملء الشاشة.
وإن رفض المتصفح ملء الشاشة، يتم تفعيل وضع بديل داخل الصفحة تلقائيًا.

## 4) بروتوكول التزامن (للمطوّرين)

الصفحتان على **المصدر نفسه (same-origin)** وتتخاطبان عبر `window.postMessage()` مع التحقّق من شكل الرسالة
ومن `event.origin`.

**من اللوحة إلى الفيديو:**

```js
{ source: "teaching-board", command: "play" | "pause" | "seek" | "rate" | "ping", time: 123.45, rate: 1.25 }
```

**من الفيديو إلى اللوحة:**

```js
{ source: "linked-video", type: "boot" | "ready" | "sync" | "state" | "error" | "closed",
  time: 123.45, state: 1, duration: 2410, rate: 1, code: null }
```

- المشغّل يرسل نبضة `sync` كل **250 مللي ثانية**.
- اللوحة تُنعّم الحركة بـ `requestAnimationFrame()`، لكنّ **الزمن الموثوق** يأتي من نبضة المشغّل.
- لا توجد حلقة تغذية راجعة: الزمن القادم من المشغّل يُحدّث العرض فقط، ولا يُعاد إرساله كأمر `seek`.
- تُستخدم `location.origin` كهدف للرسائل بعد النشر (وليس `"*"`).
- المدة الحقيقية للفيديو تُقرأ من `player.getDuration()` ولا يُعتمد على قيمة ثابتة.

### بنية بيانات المشاهد

```js
const scenes = [
  { start: 0, end: 74, chapter: "افتتاحية", kicker: "مدخل الدرس",
    title: "الخيل والليل… ثم ماذا؟", subtitle: "…", html: `<!-- محتوى اللوحة -->` }
];
```

لتعديل الشرح أو التوقيتات، عدّل مصفوفة `scenes` داخل `index.html` فقط؛
فنهاية كل مشهد تُحسب تلقائيًا من بداية المشهد التالي، وتُبنى الفصول تلقائيًا من حقل `chapter`.

## 5) حلّ المشكلات

| المشكلة | الحل |
|---|---|
| **لم يُفتح تبويب الفيديو** | المتصفح حجب النافذة المنبثقة. اسمح بالنوافذ المنبثقة للموقع، أو استخدم زر «فتح يدوي للمشغّل» الذي يظهر عند الحجب. |
| **خطأ يوتيوب 153 (أو 150/101)** | يجب نشر الصفحة عبر **HTTPS/HTTP** وعدم فتحها من `file://`. المشغّل يُنشأ داخل صفحة حقيقية بمصدر صحيح — لا `about:blank` ولا `blob:` ولا `document.write()`. إن استمرّ الخطأ فالمالك يمنع التضمين؛ استخدم زر «مشاهدة على يوتيوب». |
| **اللوحة لا تتحرّك مع الفيديو** | تأكّد أن تبويب الفيديو هو `video_player.html` (وليس تبويب يوتيوب العادي)، فتبويب يوتيوب الخارجي **لا يمكن مزامنته** بسبب قيود الأمان بين المصادر المختلفة. |
| **كُتب «انقطع الاتصال»** | أُغلق تبويب المشغّل أو حُدِّث. اضغط «افتح الفيديو المرتبط» مرة أخرى؛ يعود الاتصال دون تحديث اللوحة. |
| **واجهة يوتيوب لم تُحمَّل** | حاجب إعلانات أو انقطاع شبكة؛ عطّل الحاجب لهذا الموقع وحدّث الصفحة. |
| **اللوحة تعمل بلا فيديو** | هذا مقصود: أزرار التشغيل والفصول تعمل بتوقيت محلّي حتى تربط الفيديو، فتستطيع المراجعة بلا إنترنت. |

## 6) ملاحظات الجودة

- بلا `eval()` وبلا `document.write()`.
- بلا خطوط أو صور خارجية — كل الزخارف CSS و SVG مضمّنة.
- بلا تتبّع أو تحليلات أو مفاتيح API.
- تخطيط RTL كامل، ومتجاوب مع الجوال واللوحي وسطح المكتب.
- يحترم `prefers-reduced-motion`، ويستخدم أزرارًا دلالية يمكن الوصول إليها بلوحة المفاتيح.
- المصدر الوحيد الخارجي هو واجهة مشغّل يوتيوب (مطلوبة للتزامن).
