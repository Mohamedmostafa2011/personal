Use this in Zoom

    

      This page cannot appear in Zoom by itself. Browsers are sandboxed and
      cannot create a camera device. Zoom only sees cameras that have a driver.
      OBS Virtual Camera is the bridge — without it running, there is nothing
      for Zoom to pick.
    

    
    
      
  1. Install OBS Studio (free) and open it.
    2. 
      
  2. In Sources click + → Browser → OK.
    3. 
      
  3. Paste this page's address into URL:
        
    
          
          
        
    
        
      
    4. 
      
  4. Set Width 1280, Height 720, FPS 30 → OK.
    5. 
      
  5. Tick Clean mode above so OBS captures only the framed video.
    6. 
      
  6. Right-click the preview → Resize output to source (optional).
    7. 
      
  7. Click Start Virtual Camera on the right-hand OBS panel.
        This is the step everyone misses.
    8. 
      
  8. Fully quit and reopen Zoom — it only scans for cameras at launch.
    9. 
      
  9. Zoom → Settings → Video → Camera → pick OBS Virtual Camera.
    10. 
    

    

      Still not listed in Zoom? The virtual camera button in OBS must say
      Stop Virtual Camera (meaning it is live). On Windows, run the OBS
      installer once more and ensure the virtual-camera component is installed.
      Alternatives to OBS: Camo Studio, Snap Camera, or
      v4l2loopback on Linux.
