نشر العرض على GitHub Pages
==========================

الملفات التي تُرفع معًا داخل مجلد النشر:
- index.html
- video_player.html
- .nojekyll (اختياري)

الطريقة المقترحة: مجلد docs
--------------------------
1. أنشئ مستودعًا جديدًا على GitHub، أو افتح مستودعًا موجودًا.
2. أنشئ داخله مجلدًا اسمه docs.
3. ارفع الملفات الثلاثة السابقة داخل docs مباشرةً.
   يجب أن يكون المسار: docs/index.html وليس docs/اسم-مجلد/index.html
4. افتح Settings في المستودع.
5. اختر Pages.
6. تحت Build and deployment اختر:
   Source: Deploy from a branch
   Branch: main
   Folder: /docs
7. اضغط Save وانتظر حتى يكتمل النشر.
8. افتح الرابط الذي يعرضه GitHub، ويكون غالبًا:
   https://USERNAME.github.io/REPOSITORY/
9. اسمح للموقع بفتح نافذة الفيديو المنبثقة.

بديل
----
يمكن وضع الملفات في جذر المستودع ثم اختيار Folder: / (root).
GitHub Pages بالنشر من فرع لا يسمح عادةً باختيار مجلد عشوائي؛ استخدم الجذر أو docs.

ملء الشاشة
-----------
يوجد زر «ملء الشاشة» أعلى العرض. ويمكن أيضًا ضغط مفتاح F.
زر YouTube داخل تبويب الفيديو يوفّر ملء الشاشة للفيديو نفسه.

ملاحظات
-------
- لا ترفع ملفات BAT أو PowerShell إلى Pages؛ ليست مطلوبة للنسخة المنشورة.
- index.html وvideo_player.html يجب أن يبقيا في المجلد نفسه.
- GitHub Pages يستخدم HTTPS، لذلك لا يظهر خطأ YouTube 153 الخاص بصفحات file://.
